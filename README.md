# zip-sync

LAN 上の zip をダウンロードして、このバッチと同じ場所に解凍します。各 PC にコピーして実行するファイルは [sync.bat](sync.bat) だけです。

## 使い方

1. `sync.bat` を同期したい PC にコピーする。
2. ダブルクリックする。
3. 同じフォルダに `芝浦祭2026_ゲーム` ができる。

もう一度実行すると、そのフォルダを削除してから最新の zip を解凍します。ダウンロードに失敗した場合は、すでにあるフォルダは残します。

## 設定

[sync.bat](sync.bat) の先頭にある次の 2 行だけを変更します。

```powershell
::CONFIG ZipUrl=http://192.168.10.2/games.zip
::CONFIG DestName=芝浦祭2026_ゲーム
```

- `ZipUrl` はダウンロードする zip の URL です。
- `DestName` は解凍先のフォルダ名です。パスではなく、フォルダ名だけを指定します。
